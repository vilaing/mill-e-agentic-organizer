Coursework, job search, calendar, and inbox in one conversation.

Mill-E Agentic Organizer is an AI assistant for college students. Tell it what's going on, and it updates your assignments, tracks your applications, and rewards you for making progress.

Try the demo Sign in with Google

The demo needs no account and uses sample data.

What it does

Tracks assignments

Add work in plain language, break it into milestones, and see what's due next.

Try saying Add my bio lab report, due Friday. It's pretty hard. add_assignment

Runs your job search

Keep each application's stage, next step, and deadline in one pipeline.

Try saying I got an interview with Northwind next Tuesday. upsert_recruiting

Rewards progress

Earn points for starting and finishing work, then spend them on breaks and treats.

Try saying I finished problem set 6. What can I redeem? complete_assignment list_awards

Checks your day

Ask about your calendar and inbox, schedule time, and prepare replies.

Try saying What's on my calendar tomorrow? Block off two hours to study. list_upcoming_events create_event

How it's built

Agent loop

Claude chooses from typed tools, Python runs them, and the results feed the next step until the request is done.

Rules for points

Assignment rewards are calculated in code, so the model can't award a different amount from one run to the next.

Isolated visitors

Each browser gets its own SQLite database, selected per request without changing any tool code.

One tool set, two interfaces

The same tool definitions power this app and an MCP server for other AI clients.

If you sign in with Google

  • You get a blank workspace connected to your real inbox and calendar.
  • The agent saves email as Gmail drafts for you to review. It can't send mail from this site.
  • Email senders, subjects, and previews, plus calendar events the agent reads, are sent to Anthropic's Claude API to answer you.
  • Your Google access is held in server memory only. Signing out cancels it and deletes the workspace.
  • Sign-in is open only to approved test accounts, and Google will warn you that this app is unverified.
